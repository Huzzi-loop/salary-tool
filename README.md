# Salary Management Tool

Project overview

A clean monorepo scaffold for a production-ready full-stack "Salary Management Tool". This repository contains minimal, extensible structure for a Node.js backend and a React + Vite frontend. Business logic and full frameworks will be added later.

Tech stack

- Backend: Node.js (Express to be added later)
- Frontend: React with Vite (to be added later)

Setup

1. Install dependencies at the root (uses npm workspaces):

   npm install

2. To run both services concurrently (placeholder dev scripts currently):

   npm run dev

Running services

- Backend (placeholder):

  npm run backend

- Frontend (placeholder):

  npm run frontend

Notes

- This scaffold intentionally does not implement the Express app or the React app yet — only structure and basic package manifests are provided.
- Add actual dev scripts and dependencies in each workspace when implementing features.
